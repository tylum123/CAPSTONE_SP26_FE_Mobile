# Config Directory
- **Chức năng**: Chứa các file định cấu hình, setup thông số cho ứng dụng (vd: config biến môi trường, thông số thư viện, file cấu hình Axios base...).
- **Luồng hoạt động**: Thường được import tại lúc khởi tạo (bootstrap) ứng dụng ở file `App.tsx` hoặc `index.ts`, hoặc được load vào `src/services` làm base URL.
