# Navigation Directory
- **Chức năng**: Cấu hình bộ máy chuyển hướng của toàn ứng dụng, thiết lập sơ đồ luồng ứng dụng cho React Navigation (Stack, Bottom Tabs...).
- **Luồng hoạt động**: Định nghĩa `<NavigationContainer>` và các màn hình chính. Nó import và kết nối nhiều màn hình từ thư mục `src/screens` thành một luồng (flow) như luồng Đăng nhập, luồng Người lao động, luồng Chủ vườn.
